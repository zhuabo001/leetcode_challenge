在 JavaScript 中，`Array.prototype.sort()` 方法的行为会根据是否传入**比较函数**（排序函数）而产生显著差异，核心区别在于排序规则的不同：

### 1. 不添加比较函数（默认排序）

当 `sort()` 不传入任何参数时，会使用**默认排序规则**：

- 先将数组中的所有元素**转换为字符串**，然后按照字符的 **Unicode 码点顺序** 进行排序。

#### 特点与问题：

- **字符串排序可能符合直觉**：对于纯字符串数组，默认排序通常与“字典序”一致（因为 Unicode 码点顺序对字母、数字的排序和日常认知基本一致）。  
  例如：

  ```js
  const strs = ['banana', 'apple', 'cherry'];
  strs.sort(); // 结果：['apple', 'banana', 'cherry']（按字母顺序）
  ```

- **数字排序会出问题**：对于数字数组，默认排序会先将数字转为字符串，再比较 Unicode 码点，这会导致与“数值大小”无关的排序结果。  
  例如：

  ```js
  const nums = [10, 2, 20, 1];
  nums.sort(); // 结果：[1, 10, 2, 20]（不符合数值升序预期）
  // 原因：转换为字符串后是 "10"、"2"、"20"、"1"，比较首个字符的 Unicode 码点："1" < "10" < "2" < "20"
  ```

- **混合类型排序不可控**：如果数组包含多种类型（如数字、字符串、对象等），默认排序会将所有元素转为字符串后比较，结果往往不符合预期。  
  例如：
  ```js
  const mixed = [10, '2', 3, '1'];
  mixed.sort(); // 结果：['1', 10, '2', 3]（完全按字符串 Unicode 码点排序）
  ```

### 2. 添加比较函数（自定义排序）

当传入比较函数（格式为 `(a, b) => { ... }`）时，`sort()` 会根据函数的返回值决定元素 `a` 和 `b` 的顺序，从而实现自定义排序规则。

比较函数的逻辑：

- 若返回**负数**：`a` 排在 `b` 前面（`a < b`）；
- 若返回**0**：`a` 和 `b` 位置不变；
- 若返回**正数**：`b` 排在 `a` 前面（`a > b`）。

#### 常见场景：

- **数字升序/降序**：

  ```js
  const nums = [10, 2, 20, 1];
  // 升序（按数值大小）
  nums.sort((a, b) => a - b); // 结果：[1, 2, 10, 20]
  // 降序
  nums.sort((a, b) => b - a); // 结果：[20, 10, 2, 1]
  ```

- **按对象属性排序**：

  ```js
  const users = [
    { name: 'Bob', age: 25 },
    { name: 'Alice', age: 30 },
    { name: 'Charlie', age: 20 },
  ];
  // 按 age 升序
  users.sort((a, b) => a.age - b.age);
  // 结果：[{name: 'Charlie', age:20}, {name: 'Bob', age:25}, {name: 'Alice', age:30}]
  ```

- **忽略大小写的字符串排序**：
  ```js
  const strs = ['Banana', 'apple', 'Cherry'];
  // 默认排序会因大写字母 Unicode 码点更小而排在前面
  strs.sort(); // 结果：['Banana', 'Cherry', 'apple']
  // 忽略大小写排序
  strs.sort((a, b) => a.toLowerCase().localeCompare(b.toLowerCase()));
  // 结果：['apple', 'Banana', 'Cherry']
  ```

### 总结：核心区别

| 场景     | 不添加比较函数（默认）                   | 添加比较函数（自定义）                         |
| -------- | ---------------------------------------- | ---------------------------------------------- |
| 排序依据 | 元素转为字符串后的 Unicode 码点顺序      | 比较函数的返回值（可自定义规则：数值、属性等） |
| 适用场景 | 纯字符串数组（且需按 Unicode 顺序）      | 数字数组、对象数组、需特殊规则的字符串数组等   |
| 典型问题 | 数字排序不符合数值大小，混合类型排序混乱 | 无默认问题，完全由自定义逻辑控制               |

简单来说：默认排序是“字符串 Unicode 排序”，适合简单字符串；自定义排序通过比较函数实现任意规则，是处理数字、对象等场景的必须选择。
